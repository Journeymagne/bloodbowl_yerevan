# Релиз 2.1.0 «подготовка к переезду» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** выпустить в `main` релиз 2.1.0 с механикой безопасного переезда на 3.0: режим техобслуживания (флаг-файл, 503, самодостаточная страница, обход с loopback), перезагрузка открытых вкладок, команды `maintenance:on|off|status`, дамп перед миграцией в деплое.

**Architecture:** сервер читает флаг-файл на лету (`server/http/maintenance-flag.mjs`) и до роутинга решает, пропустить запрос или ответить 503 (`server/http/maintenance.mjs`). Страница `public/maintenance/` не зависит от модулей приложения: свои CSS и JS, палитры 0.9.1, опрос `/api/health`. Деплой вызывает `npm run deploy:migrate`: если миграции есть, сначала снимается дамп `premigrate`, без него схема не меняется.

**Tech Stack:** Node.js (ES-модули, `node --test`), `pg`, vanilla JS в браузере, PostgreSQL 16 в Docker, GitHub Actions + pm2.

**Spec:** `docs/superpowers/specs/2026-10-14-redesign-rollout-design.md` §1 (а также §4.1, §5.2). Мастер-план: `docs/superpowers/plans/2026-10-14-redesign-rollout.md`, фаза П.

## Global Constraints

- Ветка `release/2.1.0` от `origin/main` в отдельном worktree; PR в `main`; вливает **только владелец**.
- Без новых зависимостей: в `package.json` → `dependencies` остаётся один `pg`.
- CSP сайта: `script-src 'self'`, `style-src 'self'` — никакого inline JS, никаких `style="…"` в разметке; CSSOM из внешнего скрипта допустим, но эта страница обходится без него.
- Каждая строка интерфейса приложения — через `t()`; новый код ошибки API — в `API_ERRORS` и `error.<CODE>` в `src/i18n/en.json` и `src/i18n/ru.json` (`test/api-errors.test.mjs`).
- Бюджеты `scripts/check-budgets.json`: 600 строк на файл, 80 на функцию, 0 недостижимых функций; `server/server.mjs` ≤ 149 строк; бюджеты только уменьшаются.
- Комментарии в коде — по-английски, плотность и тон как у соседних файлов (doc-комментарий модуля объясняет «почему»).
- Флаг: `/etc/bloodbowl-league/maintenance.json`, переопределение `MAINTENANCE_FILE`; поля `{kind: "planned"|"unplanned", startsAt, endsAt}`.
- Обход техобслуживания — только `request.socket.remoteAddress` ∈ {`127.0.0.1`, `::1`, `::ffff:127.0.0.1`}; `X-Forwarded-For` не читается.
- `/api/health` во время техобслуживания отвечает `200` с полем `maintenance`.
- Дамп перед миграцией: `gata_league-premigrate-YYYYMMDD-HHMMSS.dump`, ротация его не трогает.
- Кеш палитры 3.0: ключ localStorage `gata-league-palette`, JSON `{mode: "light"|"dark"|"system", light: <key>, dark: <key>}`; 2.x — `gata-league-theme` с id темы.

## Review Focus

1. **Битый или нечитаемый флаг-файл** → сайт закрыт как «сбой», а не открыт; в лог одно предупреждение, не каждые 2 секунды (Task 2).
2. **Публичный запрос с `X-Forwarded-For: 127.0.0.1`** → обхода нет, отдаётся страница техобслуживания (Task 3).
3. **`/api/health` во время техобслуживания** → `200`, `maintenance` заполнен; иначе health check деплоя откатит код (Task 3).
4. **Открытая вкладка ловит `MAINTENANCE` на автосохранении, `sessionStorage` заблокирован** → одна перезагрузка, без цикла (Task 5).
5. **Дамп перед миграцией упал** → миграции не применены, деплой возвращает код на диске к прежнему коммиту; помеченные дампы ночная ротация не удаляет (Tasks 7–8).

```js
/**
 * The site administrator's account, brought in line with the env file at boot.
 *
 * Moved out of server.mjs by release 2.1.0, which needed the lines for the
 * maintenance gate: server.mjs is held to a line budget, and this was the one
 * part of it that is not starting the server.
 *
 * Every boot rewrites the password and Telegram from the env file, so the file
 * stays the single place an operator changes them.
 */
import { normalizeLogin } from "../api/serializers.mjs";
import { hashPassword } from "./session.mjs";

/**
 * @param {{query: (sql: string, params: unknown[]) => Promise<unknown>}} pool
 * @param {Record<string, string|undefined>} [env]
 * @returns {Promise<string>} the admin login, for the startup log
 */
export async function ensureAdminAccount(pool, env = process.env) {
  const login = env.ADMIN_LOGIN || "admin";
  const password = env.ADMIN_PASSWORD || "change-me-site-admin-password";
  const telegram = env.ADMIN_TELEGRAM || "@admin";
  await pool.query(
    `INSERT INTO users (login, login_key, telegram, password_hash, is_admin)
     VALUES ($1, $2, $3, $4, TRUE)
     ON CONFLICT (login_key) DO UPDATE
       SET telegram = EXCLUDED.telegram,
           password_hash = EXCLUDED.password_hash,
           is_admin = TRUE,
           updated_at = now()`,
    [login, normalizeLogin(login), telegram, hashPassword(password)],
  );
  return login;
}
```

`server/http/maintenance-flag.mjs`:

```js
/**
 * Maintenance mode's flag: where it lives, what it says, who it applies to.
 *
 * Release 2.1.0, ahead of the 3.0 cutover. The version that is live on the day
 * of a migration has to be the one that knows how to say "back soon", so this
 * ships before the migration it exists for.
 *
 * The flag is a file, not a database setting, because the database is the
 * thing being worked on. It is re-read while the server runs: switching the
 * mode is `npm run maintenance:on|off`, never a restart.
 *
 * Requests from the machine itself pass. That is how the owner looks at the new
 * version through an SSH tunnel before opening it to the league. Caddy reaches
 * Node from the docker network, never from loopback, and X-Forwarded-For is not
 * consulted, so a request from outside cannot claim to be local.
 *
 * Kept free of server imports so scripts/maintenance.mjs can use it too.
 */
import { promises as fs } from "node:fs";

export const DEFAULT_MAINTENANCE_FILE = "/etc/bloodbowl-league/maintenance.json";
export const MAINTENANCE_KINDS = Object.freeze(["planned", "unplanned"]);

const LOOPBACK = new Set(["127.0.0.1", "::1", "::ffff:127.0.0.1"]);
const PAGE_ASSET_PREFIXES = ["/public/maintenance/", "/assets/fonts/"];
const UNREADABLE = Object.freeze({ kind: "unplanned", startsAt: null, endsAt: null, invalid: true });

export function maintenanceFilePath(env = process.env) {
  return env.MAINTENANCE_FILE || DEFAULT_MAINTENANCE_FILE;
}

function isoOrNull(value) {
  if (typeof value !== "string" || !value) return null;
  const time = Date.parse(value);
  return Number.isNaN(time) ? null : new Date(time).toISOString();
}

/**
 * A flag that cannot be read as intended still means maintenance: whoever
 * wrote it wanted the site closed. It reads as unplanned, with no times.
 */
export function parseMaintenanceFlag(text) {
  let raw;
  try {
    raw = JSON.parse(text);
  } catch {
    return { ...UNREADABLE };
  }
  if (!raw || typeof raw !== "object" || Array.isArray(raw) || !MAINTENANCE_KINDS.includes(raw.kind)) {
    return { ...UNREADABLE };
  }
  return { kind: raw.kind, startsAt: isoOrNull(raw.startsAt), endsAt: isoOrNull(raw.endsAt) };
}

export function isLoopbackAddress(address) {
  return LOOPBACK.has(String(address ?? ""));
}

/**
 * What one request gets while the flag is up.
 *
 * @returns {"pass"|"api"|"page"}
 */
export function maintenanceAction(pathname, remoteAddress, flag) {
  if (!flag || isLoopbackAddress(remoteAddress)) return "pass";
  if (pathname === "/api/health") return "pass";
  if (pathname.startsWith("/api/")) return "api";
  if (PAGE_ASSET_PREFIXES.some((prefix) => pathname.startsWith(prefix))) return "pass";
  return "page";
}

/**
 * The flag as of now, read at most once per interval: the page alone asks for
 * half a dozen files, and each of them would otherwise touch the disk.
 */
export function createMaintenanceReader({
  filePath,
  readFile = fs.readFile,
  now = Date.now,
  minIntervalMs = 2000,
  warn = console.warn,
}) {
  let checkedAt = -Infinity;
  let flag = null;
  return {
    async current() {
      if (now() - checkedAt < minIntervalMs) return flag;
      checkedAt = now();
      const previous = flag;
      try {
        flag = parseMaintenanceFlag(await readFile(filePath, "utf8"));
      } catch (error) {
        flag = error?.code === "ENOENT" ? null : { ...UNREADABLE, reason: error?.message };
      }
      if (flag?.invalid && !previous?.invalid) {
        warn(`[maintenance] ${filePath} could not be read as a flag (${flag.reason ?? "invalid contents"}); the site stays closed`);
      }
      return flag;
    },
  };
}
```

```js
/**
 * The maintenance gate: the first thing every request meets.
 *
 * Answers with 503 while the flag file is up (server/http/maintenance-flag.mjs
 * says why it is a file and who is let through), and says nothing otherwise so
 * the request carries on to the API or the static files as usual.
 *
 * The page is read from disk on every refusal rather than cached: it is small,
 * and a page updated by a deploy must not need a restart to show.
 */
import "../config/env.mjs";

import { promises as fs } from "node:fs";
import path from "node:path";

import { errorPayload } from "./errors.mjs";
import { createMaintenanceReader, maintenanceAction, maintenanceFilePath } from "./maintenance-flag.mjs";
import { sendJson } from "./responses.mjs";
import { staticRoot } from "./static.mjs";

const RETRY_AFTER_SECONDS = "120";

/**
 * @param {{reader: {current(): Promise<object|null>}, loadPage: () => Promise<Buffer|string>}} deps
 * @returns {(request, response, url: URL) => Promise<boolean>} true when answered
 */
export function createMaintenanceGate({ reader, loadPage }) {
  return async function answer(request, response, url) {
    const flag = await reader.current();
    const action = maintenanceAction(url.pathname, request.socket?.remoteAddress, flag);
    if (action === "pass") return false;
    if (action === "api") {
      response.setHeader?.("Retry-After", RETRY_AFTER_SECONDS);
      sendJson(response, 503, errorPayload("MAINTENANCE"));
      return true;
    }
    response.writeHead(503, {
      "Content-Type": "text/html; charset=utf-8",
      "Cache-Control": "no-store",
      "Retry-After": RETRY_AFTER_SECONDS,
    });
    response.end(await loadPage());
    return true;
  };
}

const reader = createMaintenanceReader({ filePath: maintenanceFilePath() });
const pagePath = path.join(staticRoot, "public", "maintenance", "index.html");

export const answerMaintenance = createMaintenanceGate({ reader, loadPage: () => fs.readFile(pagePath) });

/** The flag as the health check reports it: no internal fields. */
export async function currentMaintenance() {
  const flag = await reader.current();
  return flag ? { kind: flag.kind, startsAt: flag.startsAt, endsAt: flag.endsAt } : null;
}
```

`public/maintenance/palettes.mjs`:

```js
/**
 * Which of the 3.0 palettes the maintenance page wears.
 *
 * The page is served while the app is not, so it cannot ask the server or the
 * app's modules. What it has is the browser's cache of the reader's choice:
 *
 * - 3.0 stores `gata-league-palette` as JSON: {mode: "light"|"dark"|"system",
 *   light: <key>, dark: <key>} (src/core/theme.mjs writes it from stage 4 of
 *   the redesign — the two must agree);
 * - 2.x stored one theme id under `gata-league-theme`, mapped below to the
 *   nearest palette. src/core/theme.mjs takes the same table in stage 4.
 *
 * The colours themselves live in maintenance.css, one block per key, so the
 * page sets two attributes and never a style.
 */
export const PALETTE_STORAGE_KEY = "gata-league-palette";

export const PALETTE_KEYS = Object.freeze({
  light: Object.freeze(["grass", "parchment", "ice", "imperial"]),
  dark: Object.freeze(["night", "dungeon", "embers", "abyss"]),
});

export const DEFAULT_PALETTE = Object.freeze({ light: "grass", dark: "night" });

export const LEGACY_THEME_PALETTE = Object.freeze({
  "dark-gata": Object.freeze(["dark", "night"]),
  "dark-dugout": Object.freeze(["dark", "embers"]),
  "dark-warpstone": Object.freeze(["dark", "dungeon"]),
  "light-parchment": Object.freeze(["light", "parchment"]),
  "light-sideline": Object.freeze(["light", "grass"]),
  "light-altdorf": Object.freeze(["light", "ice"]),
});

function parseChoice(text) {
  if (typeof text !== "string") return null;
  try {
    const value = JSON.parse(text);
    return value && typeof value === "object" && !Array.isArray(value) ? value : null;
  } catch {
    return null;
  }
}

/**
 * @param {{palette: string|null, legacyTheme: string|null, prefersDark: boolean}} stored
 * @returns {{mode: "light"|"dark", key: string}}
 */
export function paletteFor({ palette, legacyTheme, prefersDark }) {
  const systemMode = prefersDark ? "dark" : "light";
  const choice = parseChoice(palette);
  if (choice) {
    const mode = choice.mode === "light" || choice.mode === "dark" ? choice.mode : systemMode;
    const key = PALETTE_KEYS[mode].includes(choice[mode]) ? choice[mode] : DEFAULT_PALETTE[mode];
    return { mode, key };
  }
  const legacy = Object.hasOwn(LEGACY_THEME_PALETTE, legacyTheme ?? "") ? LEGACY_THEME_PALETTE[legacyTheme] : null;
  if (legacy) return { mode: legacy[0], key: legacy[1] };
  return { mode: systemMode, key: DEFAULT_PALETTE[systemMode] };
}
```

```js
export function fill(template, params) {
  return template.replace(/\{(\w+)\}/g, (match, name) => (Object.hasOwn(params, name) ? String(params[name]) : match));

export function formatClock(ms, locale) {
  return new Intl.DateTimeFormat(locale === "ru" ? "ru-RU" : "en-GB", {
    hour: "2-digit", minute: "2-digit", hourCycle: "h23", timeZone: TIME_ZONE,
  }).format(ms);

function plannedView(flag, now, locale, strings) {
  const start = flag.startsAt ? Date.parse(flag.startsAt) : null;
  const end = flag.endsAt ? Date.parse(flag.endsAt) : null;
  const window = start || end
    ? { startsAt: start ? formatClock(start, locale) : "—", endsAt: end ? `≈ ${formatClock(end, locale)}` : "—" }
    : null;
  const progress = start && end && end > start ? Math.round(Math.min(1, Math.max(0, (now - start) / (end - start))) * 100) : null;
  let meta = "";
  if (end && end > now) meta = fill(strings.remaining, { minutes: Math.ceil((end - now) / 60000) });
  else if (end) meta = strings.overdue;
  return { state: "planned", chip: strings.plannedChip, title: strings.plannedTitle, lead: strings.plannedLead, window, progress, meta };
}

/**
 * @param {{kind: "planned"|"unplanned", startsAt: string|null, endsAt: string|null}|null} flag
 * @param {number} now epoch milliseconds
 * @param {"ru"|"en"} locale

export function describeMaintenance(flag, now, locale) {
  const strings = STRINGS[locale];
  if (!flag) {
    return { state: "done", chip: strings.doneChip, title: strings.doneTitle, lead: strings.doneLead, window: null, progress: null, meta: "" };
  }
  if (flag.kind === "planned") return plannedView(flag, now, locale, strings);
  const meta = flag.startsAt ? fill(strings.since, { time: formatClock(Date.parse(flag.startsAt), locale) }) : strings.sinceUnknown;
  return { state: "unplanned", chip: strings.unplannedChip, title: strings.unplannedTitle, lead: strings.unplannedLead, window: null, progress: null, meta };
}
```

```js
  try {

  } catch {
    return null;
  }
}

const root = document.documentElement;

root.dataset.palette = palette.key;

function render(view) {
  slot("status").dataset.state = view.state;
  slot("chip").textContent = view.chip;
  slot("title").textContent = view.title;
  slot("lead").textContent = view.lead;
  slot("window").hidden = !view.window;
  if (view.window) {
    slot("startsAt").textContent = view.window.startsAt;
    slot("endsAt").textContent = view.window.endsAt;
  }
  slot("progressRow").hidden = view.progress === null;
  if (view.progress !== null) slot("progress").value = view.progress;
  slot("meta").textContent = view.meta;
  slot("open").hidden = view.state !== "done";
  slot("check").hidden = view.state === "done";
  slot("tips").hidden = view.state === "done";
  slot("auto").hidden = view.state === "done";

  try {
    const response = await fetch("/api/health", { cache: "no-store" });
    if (!response.ok) return undefined;
    return (await response.json()).maintenance ?? null;

    return undefined;
  }
```

`src/core/maintenance-reload.mjs`:

```js
/**
 * Send a page that is still open on the old version to the maintenance page.
 *
 * During maintenance every API call answers 503 MAINTENANCE. A coach whose tab
 * was open before the work started would otherwise see each save fail with no
 * explanation. Reloading hands them the maintenance page, which reloads them
 * again into the new version once the work is done.
 *
 * The gap is the guard against a loop: if the page reloads into the app while
 * the API still refuses, it waits before trying again. sessionStorage, not
 * localStorage (src/core/storage.mjs): the stamp belongs to this tab only.
 */
const RELOAD_KEY = "gata-league-maintenance-reload";
export const MIN_RELOAD_GAP_MS = 30_000;

export function reloadForMaintenance({
  session = globalThis.sessionStorage,
  location = globalThis.location,
  now = Date.now(),
} = {}) {
  let last = -Infinity;
  try {
    const stamp = session?.getItem(RELOAD_KEY);
    if (stamp) last = Number(stamp);
  } catch {
    // Storage refused: the reload below still happens, and the next page
    // load starts from a fresh module, so it cannot repeat in a tight loop.
  }
  if (now - last < MIN_RELOAD_GAP_MS) return false;
  try {
    session?.setItem(RELOAD_KEY, String(now));
  } catch {
    // As above.
  }
  location?.reload();
  return true;
}
```

```js
/**
 * The maintenance commands' arguments and the flag they write.
 *
 * Kept apart from the command so it can be tested without touching /etc: the
 * point of having a command at all is that nobody hand-writes JSON on the
 * server under time pressure.
 */
import { MAINTENANCE_KINDS } from "../../server/http/maintenance-flag.mjs";

const COMMANDS = ["on", "off", "status"];
const OPTIONS = { "--kind": "kind", "--starts": "starts", "--ends": "ends" };

export function parseMaintenanceArgs(argv) {
  const [command, ...rest] = argv;
  if (!COMMANDS.includes(command)) throw new Error("usage: maintenance on|off|status — the command must be on, off or status");
  const parsed = { command, kind: undefined, starts: undefined, ends: undefined };
  for (let index = 0; index < rest.length; index += 2) {
    const field = OPTIONS[rest[index]];
    if (!field) throw new Error(`unknown option ${rest[index]}; use --kind, --starts or --ends`);
    parsed[field] = rest[index + 1];
  }
  return parsed;
}

function isoOption(value, name) {
  const time = Date.parse(value);
  if (Number.isNaN(time)) throw new Error(`${name} must be a date and time, e.g. 2026-11-02T19:00+04:00`);
  return new Date(time).toISOString();
}

export function buildMaintenanceFlag({ kind = "planned", starts, ends }, now = new Date()) {
  if (!MAINTENANCE_KINDS.includes(kind)) throw new Error("--kind must be planned or unplanned");
  const startsAt = starts ? isoOption(starts, "--starts") : now.toISOString();
  const endsAt = ends ? isoOption(ends, "--ends") : null;
  if (endsAt && Date.parse(endsAt) <= Date.parse(startsAt)) throw new Error("--ends must be after the start");
  return { kind, startsAt, endsAt };
}
```

- [ ] **Step 4: Команда**

`scripts/maintenance.mjs`:

```js
#!/usr/bin/env node
/**
 * Turn maintenance mode on or off, or say whether it is on.
 *
 *   npm run maintenance:on -- --kind planned --ends "2026-11-02T19:00+04:00"
 *   npm run maintenance:off
 *   npm run maintenance:status
 *
 * The running server notices within two seconds; nothing restarts. On the
 * server the flag lives in /etc/bloodbowl-league (root only), so run these
 * with `sudo -i`. MAINTENANCE_FILE in the env file moves it.
 */
import { promises as fs } from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";

import { loadEnvFile } from "../server/config/env-file.mjs";
import { maintenanceFilePath, parseMaintenanceFlag } from "../server/http/maintenance-flag.mjs";
import { buildMaintenanceFlag, parseMaintenanceArgs } from "./maintenance/flag.mjs";

const rootDir = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");

async function writeAtomically(file, body) {
  // Write beside the target and rename over it, so the server never reads a
  // half-written flag (it would treat that as an outage and say so).
  const temporary = `${file}.tmp-${process.pid}`;
  await fs.writeFile(temporary, body, { mode: 0o644 });
  await fs.rename(temporary, file);
}

async function describe(file) {
  try {
    const flag = parseMaintenanceFlag(await fs.readFile(file, "utf8"));
    const window = [flag.startsAt, flag.endsAt].filter(Boolean).join(" → ");
    return `maintenance: on (${flag.kind}${flag.invalid ? ", unreadable flag" : ""})${window ? ` ${window}` : ""} — ${file}`;
  } catch (error) {
    if (error.code === "ENOENT") return `maintenance: off — ${file}`;
    throw error;
  }
}

async function main() {
  await loadEnvFile(rootDir);
  const args = parseMaintenanceArgs(process.argv.slice(2));
  const file = maintenanceFilePath();
  if (args.command === "on") {
    await writeAtomically(file, `${JSON.stringify(buildMaintenanceFlag(args), null, 2)}\n`);
  } else if (args.command === "off") {
    await fs.rm(file, { force: true });
  }
  console.log(await describe(file));
}

main().catch((error) => {
  console.error(`maintenance: ${error.message}`);
  process.exitCode = 1;
});
```

`scripts/deploy/migrate-plan.mjs`:

```js
/**
 * What the deploy's schema step does, decided before it touches anything.
 *
 * A migration is the one deploy step that cannot be undone by putting the old
 * code back, so it never runs without a fresh dump to return to.
 */
export function planDeployMigration({ pending, changed }) {
  if (changed.length) {
    return { action: "refuse", message: `edited after being applied: ${changed.join(", ")}` };
  }
  if (!pending.length) return { action: "skip", message: "no pending migrations, backup skipped" };
  return { action: "backup-then-migrate", message: `pending: ${pending.map((migration) => migration.name).join(", ")}` };
}
```

- [ ] **Step 4: Команда**

`scripts/deploy-migrate.mjs`:

```js
#!/usr/bin/env node
/**
 * The deploy's schema step: `npm run db:migrate`, with a dump in front of it.
 *
 * Release 2.1.0. Before this the deploy migrated with whatever backup the
 * nightly timer had last taken, up to a day old. Now any deploy that changes
 * the schema takes a labelled dump first (gata_league-premigrate-*.dump, which
 * rotation keeps), and a failed dump means the schema is left as it was.
 */
import { spawnSync } from "node:child_process";
import path from "node:path";
import { fileURLToPath } from "node:url";
import pg from "pg";

import { loadEnvFile } from "../server/config/env-file.mjs";
import { applyMigrations, migrationStatus } from "../server/db/migrate.mjs";
import { planDeployMigration } from "./deploy/migrate-plan.mjs";

const rootDir = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");
await loadEnvFile(rootDir);

if (!process.env.DATABASE_URL) {
  console.error("deploy:migrate: DATABASE_URL is not set");
  process.exit(1);
}

const pool = new pg.Pool({ connectionString: process.env.DATABASE_URL });
try {
  const plan = planDeployMigration(await migrationStatus(pool));
  console.log(`deploy:migrate: ${plan.message}`);
  if (plan.action === "refuse") {
    process.exitCode = 1;
  } else if (plan.action === "backup-then-migrate") {
    const backup = spawnSync(process.execPath, [path.join(rootDir, "scripts", "backup-db.mjs"), "--label", "premigrate"], { stdio: "inherit" });
    if (backup.status !== 0) {
      console.error("deploy:migrate: the pre-migration backup failed; the schema was not touched");
      process.exitCode = 1;
    } else {
      const applied = await applyMigrations(pool);
      console.log(`deploy:migrate: applied ${applied.join(", ")}`);
    }
  }
} finally {
  await pool.end();
}
```
