Состояние на 2026-08-21. Ветка `refactor/stage-1`, 39 коммитов поверх `main`.

Полный план — `docs/superpowers/plans/2026-08-19-app-refactor.md`,
обоснования — `docs/superpowers/specs/2026-08-19-app-refactor-design.md`.
Этот файл — короткая сводка по задачам, чтобы не читать план целиком.

## Готово

| Задача | Результат |
|---|---|
| **1. Инструменты проверки** | `npm run check` (мёртвый код + лимиты файлов/функций), `npm run smoke`, `npm test` — 136 тестов |
| **2. Гигиена репозитория** | `dist/` и `public/data*.json` больше не в гите, мёртвые ассеты удалены, версия ассетов сведена в одно место |
| **5. Сохранение ростера** | `src/data/roster-store.mjs`: очередь на команду, точечное слияние ответа сервера, зеркало несохранённого в `localStorage`, `beforeunload`. Гонка «правка сразу после сохранения» закрыта тестом |

## Не начато

| Задача | Суть |
|---|---|
| **7. Единый редактор ростера** | Слить `screens/builder.mjs` и `screens/saved-roster.mjs` — 12 пар функций-двойников. Самый большой выигрыш по коду |
| **8. Точечный рендеринг** | Убрать полную перерисовку экрана на каждую правку: теряется фокус, скролл, раскрытые карточки |
| **9. Ростер в процессе игры** | Переосмыслена владельцем: заморозки раунда нет, вместо неё кнопка «Начать» у матча, фиксирующая стоимость обеих команд. Плюс статус Forfeit |
| **10. Информационная архитектура** | Группировка меню, публичный доступ к сезону, перенос `overviewCards` в контент-хранилище |
| **11. Данные и производительность** | Убрать двойную сериализацию в `data.json` (276 из 292 страниц лежат дважды), разделить каталог и тела страниц |
| **13. Остаток i18n-долга** | ~30 строк интерфейса и все сообщения сервера мимо `t()` |
| **14. Целостность результатов матчей** | Игрок может подтвердить собственный результат; подтверждение идёт тремя запросами без транзакции |
| **15. CSS и доступность** | 4282 строки без секций, три медиазапроса в конце файла, `aria-live` на полной перерисовке |
| **16. Контент-пайплайн** | Данные билдера добываются регулярками из прозы без проверки результата |
| **17. Сервер: производительность** | Синхронное сжатие 1,67 МБ на каждый запрос, сессии не чистятся, деплой без health-check и отката |
| **12. Приёмка** | Финальная сверка, выполняется последней |

## Что можно брать прямо сейчас

Без доступа к базе и серверу:

1. **Связать прокачку и навыки** (решение владельца от 2026-08-21). Сейчас
   «Улучшение» тратит SPP и не выдаёт ничего, а навыки и статы добавляются
   бесплатно и только повышают стоимость игрока. Нужно, чтобы улучшение
   сразу требовало выбрать, что оно дало. Попап с выбором типа и броском
   рандома — после рефакторинга, сейчас только связка модели.
2. **Шаг 3.2** — `schema.mjs`, одно описание черновика вместо четырёх.
3. **Задача 7** — единый редактор ростера.
4. **Задача 8** — точечный рендеринг.
