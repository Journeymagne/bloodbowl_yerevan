# Известные пробелы

Не баги: правила лиги, которые сайт сознательно не проверяет и оставляет на совести тренера.
Записаны, чтобы их не приняли за ошибку и не «исправили» без обсуждения. Найденные ошибки — в
[`known-bugs.md`](known-bugs.md).

Если решение пересмотрели и правило начали проверять в коде, удалите пункт из файла.

## Coach's Safe

Решено оставить на совести тренера (2026-10-03).

Правила («All Gata Changes», строки 122–126): не больше 50k за матч, тратить только после конца
сезона, при редрафте добавить до 300k к бюджету новой команды.

- Лимит 50k за матч сайт проверить не может — поле в редакторе принимает любое число.
- «Не тратить до конца сезона» соблюдается само: покупки списываются из казны, не из сейфа.
- Редрафта на сайте нет: новая команда собирается в конструкторе с бюджетом 600k, сейф не
  добавляется. Делать редрафт ради этого не стали, чтобы не усложнять сайт.
