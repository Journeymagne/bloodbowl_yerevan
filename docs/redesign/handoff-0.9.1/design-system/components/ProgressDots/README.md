# ProgressDots

Counted progress with a known maximum: a player's advancements (6), steps of a sheet flow.

**Provide:** total and done.

**Anatomy:** bars 22×6, gap `space-4`, `radius-xs`; done `accent`, rest `line-strong`; always followed by a caption with the numbers («Улучшения: 2 из 6»). Sheet step dots are the 8×6 variant with the current step 24 wide (see BottomSheet).
