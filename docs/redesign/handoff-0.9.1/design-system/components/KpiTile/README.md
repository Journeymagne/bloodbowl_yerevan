# KpiTile

Team-level figures in a 2-column grid: team value, treasury, record, diffs, inducement budget.

**Provide:** label and value (pre-formatted: `1 120k`, `4 · 1 · 1`, `+6 / +4`).

**Anatomy:** `surface-2`, `radius-xl`, padding 12 14; label 13 `muted`; value 30px `display` 700. A figure that is good news for the coach (inducements, a playoff spot) may use `g-kpi--positive` (`accent-tint`, `on-accent-tint`).

Use 2 or 4 tiles, never 3. In cards (next match) use the compact form: padding 10 12, value 17/700 body face.
