# SearchField

Filters the list below it as you type.

**Provide:** placeholder naming what can be found, `aria-label`, the change handler.

**Anatomy:** height 48, `radius-lg`, `surface-2`, padding 0 `space-14`, gap `space-10`, 18px search icon in `muted`, input 16px `ink` without border. In a scrolling flex column it needs `flex: none`.

Show a count next to the page title («24 из 82») and an empty state line «Ничего не найдено» in `muted`.
