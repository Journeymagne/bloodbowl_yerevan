# Callout

A single link that tells the coach something actionable is waiting (an advancement available, a match to start).

**Provide:** title (the news), one sub line (who / how much), destination.

**Anatomy:** `accent-tint`, `radius-xl`, min-height 56, padding 10 14; title 15/700, sub 13, chevron; all `on-accent-tint`.

At most one per screen, placed right after the summary tiles. Never for warnings or errors.
