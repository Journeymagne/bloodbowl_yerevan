# InfoBubble

A tappable fact on a dark surface that opens its explanation (the PreMatch sheet).

**Rules:** the inducement bubble sits under the name of the team that **receives** inducements, and is absent when TVs are equal. The missing-players bubble is one shared bubble under the score: «3 игрока пропускают матч» counts both teams, with Russian plural (1 игрок пропускает, 2–4 игрока пропускают, 5+ игроков пропускают); «Все игроки в строю» when nobody misses. Ends with the info icon.

`--static` (no icon, no ring) for plain facts like CAS and MVP of a past match.
