# ResultSheet

Opened by «Завершить матч». Two rows (Тачдауны, Травмы (CAS)) with a `g-score-step` for us and one for the opponent. Our TD and CAS are prefilled from what was marked in the roster during the game; the helper says so.

Footer: the outcome in display type («Победа 2:1» / «Ничья» / «Поражение»), then the CTA — «Отправить результат» for a league match (the opponent confirms, then league points are awarded), «Сохранить результат» for a friendly (saved at once).
