# StatStrip

A player's five characteristics as tiles, top of the profile.

**Provide:** MA, ST, AG, PA, AV values and which were improved.

**Anatomy:** 5-column grid, gap 6. Tile `surface-2`, `radius-lg`, padding 8 0 10; label `col-label` `muted`; value 26px `display` 700. Improved: `accent-tint` tile, value in `accent`. AG/PA/AV carry `+`.

Order is always MA ST AG PA AV.
