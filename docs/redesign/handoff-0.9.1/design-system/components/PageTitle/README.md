# PageTitle

The heading set: back link, H1, section H2 with a count, sub-section H3 and the overline group label.

**Provide:** the text; for H2 an optional count; for H1 an optional right-aligned meta (`82 из 82`, `после 6 тура`).

- **Back link** (`g-back`): 14px/600 `accent` with a left chevron, only on second-level pages inside a tab (a reference article → «Справочник»).
- **H1** `page-title` 32 — content pages only (reference). Table screens start with H2.
- **H2** `section` 26 with the count in 15px/500 `muted`: «Активный состав 11», «Пропускают матч 1».
- **H3** `section-s` 24 for blocks inside a profile or article.
- **Overline** 13px/700 uppercase, letter-spacing .08em, `muted`: groups of list rows.

**Don't** number sections or add decorative eyebrows.
