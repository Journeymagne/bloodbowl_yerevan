# NumberBadge

Identity marks: the player's shirt number in a circle coloured by position, and the skill-category letter in a rounded square.

**Provide:** number + position (→ `pos-blitzer`, `pos-catcher`, `pos-thrower`, `pos-lineman`, `pos-big`; unknown positions use `pos-lineman`); or category letter A D G M P S (→ `cat-*`), traits show `•` on `cat-trait`.

**Sizes:** player badge `size-badge` 36, `radius-full`, `badge-num` 17 white. Profile header: 60px, 28px digits, 2px `header-ink` ring. Category badge 28 in lists, 36 (`radius-md`) on category cards, 44 (`radius-lg`) in a skill sheet.

**Don't** use the badge colours for text or large fills, or rely on colour alone: the letter/number is always there.
