# SideNav

Desktop navigation: a 232px `pitch-900` column on every desktop page.

**Top:** team switcher button (crest, name, race · league, chevron) → popover with the coach's teams and «Новая команда».
**Nav:** Обзор · Состав · Сезон · Справочник · Тренер; current item on `rgba(255,255,255,.12)`.
**Bottom:** the match card mirrors the StatusChip lifecycle — «Следующий матч / Начать матч», «● Идёт игра / Завершить матч» (white button), then the sent result. Under it the language switch (RU / EN) and the SiteFooter line.

On mobile the same destinations are header tabs: Команда · Состав · Матчи · Таблица · Справочник · Тренер · Настройки (the row scrolls; screens near the end open scrolled to the end).
