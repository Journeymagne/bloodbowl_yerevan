# TextField

Label (13/600 `muted`) over a 48px input on `surface` with the inset ring, optional helper line. A Save button appears next to the field only when the value changed.

**Password change** (a separate sheet / dialog): current, new, repeat; a 3-segment meter (Слабый / Средний / Надёжный) and live checks (≥ 8 символов, отличается от текущего, пароли совпадают). The CTA stays disabled until every check passes; then a success state «Пароль изменён».
