# ResultPill

Match outcome at the start of a result row.

**Provide:** win, draw or loss → «В» on `accent`, «Н» on `neutral-result`, «П» on `danger`; white 14/700, 30×30 (28 in compact lists), `radius-sm`.

The letter carries the meaning; colour only reinforces it. Follow it with opponent (16/500), a caption line (Тур · раса · CAS) and the score in 26px `display` right-aligned.
